- **Blocage** : historique de commits mal organisé, dates décalées*

- **Message / constat**  : Mon dépôt d'essai fonctionnait, mais en relisant l'historique (git log --oneline), mes commits n'étaient pas bien découpés. Par exemple, app.js et synthese.js avaient été envoyés dans le même commit.

- **Ce que j'ai essayé** : j'avais d'abord travaillé sur un brouillon avec un dépôt en ligne, pour vérifier que mes commits et mes envois fonctionnaient. Puis j'ai essayé de corriger l'historique (renommer des commits, séparer un commit, git commit --amend, git reset HEAD~1).

-**Solution** : j'ai décidé de reprendre le projet à zéro depuis le kit, étape par étape, avec un commit par étape. J'harmonise maintenant mes commits et mon code.

- **Conséquence** : les dates de la colonne « Fait le » sont décalées par rapport au planning prévu. Le travail a été refait, puis harmonisé, au lieu d'avancer en ligne droite.
- **Ce que j'ai appris** : faire un commit par étape dès le départ, et vérifier l'historique avec git log --oneline avant chaque envoi.
